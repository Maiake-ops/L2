02 / THE COMPONENTS

Only what earns its place.

Technical documentation ↗
01

Minimal memory footprint ↗

A small console system, with explicit size gates and tools to measure memory on your hardware.

02

rcl2 init system ↗

A freestanding C and Rust supervisor. PID 1, service startup, process reaping and shutdown.

03

L2PM package management ↗

Content-addressed storage, deterministic archives and profiles. Build recipes you can read.

04

Lightweight userspace ↗

musl, BusyBox and dash. A static core toolset with a dedicated POSIX shell.

05

Your kernel configuration ↗

A minimal Linux configuration with explicit hardware support. Adjust the fragment to fit your machine.

06

Build from source ↗

Pinned sources, hashes and a single build entry point. Inspect each component and rebuild it yourself.
