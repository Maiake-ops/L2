CONTRIBUTE

Small, reviewable changes.

Report reproducible issues with your commit, host distribution, hardware, commands and relevant logs. Remove credentials and private information from logs before sharing them.

For code changes, fork the repository, create a focused branch, run the relevant checks, and describe what changed and how you tested it in a pull request.
