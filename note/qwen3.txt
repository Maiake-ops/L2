9. METHODOLOGY RULES (hard-won; keep for all future measurements)
--------------------------------------------------------------------------------
- ISO boot AUTHORITATIVE; -kernel/-initrd reads ~1 MiB high (fw_cfg keeps
  initrd in guest memory). Label direct mode as comparison only.
- -smp 2 consistent (1 vs 2 changes readings ~1 MiB); settle >=40s (25s
  once read 11192 vs 40s 9128 on same ISO); min of 3 samples;
  used = MemTotal - MemAvailable; reserved = installed - MemTotal.
- Serial framing: CRLF sends (bare LF dropped) + 0.7s pre-type settle;
  BROKEN markers (echo L2SPAWN''OK -> output L2SPAWNOK) so echoed input
  never fakes completion; split on echoed command for output extraction.
- Marker completion != workload success (14M burst OOM lesson).
- KVM logs NO exceptions; use -accel tcg -d int,cpu_reset -D for faults;
  -debugcon for OVMF (RELEASE = silent); -no-reboot makes QEMU exit on
  guest reset (exit 0 ≠ timeout).
- retain_initrd BARE flag only (=1 silent no-op).
- SLUB_TINY -> /sys/kernel/slab per-cache stats EMPTY; need SLUB_DEBUG
  build for attribution (absolutes then overstate TINY; ranking is signal).
- glob tool SKIPS gitignored paths (build/ invisible) -> use ls for build
  artifacts; read_file for content.
- Limine panics are ANSI-interleaved char-by-char -> strip escapes before
  classification; "Out of memory" in Limine text must not classify as
  kernel oom-kill (signature order).
- Check `date` before timestamping records.
- Two concurrent ./l2 build kernel runs rm -rf the SAME source tree ->
  mutual destruction; separate L2_BUILD_DIR per concurrent builder.
- bzImage payload_offset is relative to protected-mode base; xz needs
  --single-stream (trailing padding).
