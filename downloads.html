FROM SOURCE

One entry point.

The core build produces a hybrid BIOS/UEFI ISO in build/out/l2.iso. Dependencies are installed on your build host; review the package-manager prompts.

Complete build instructions →
git clone --single-branch --branch main https://github.com/Maiake-ops/L2.git
cd L2
./l2 deps install
./l2 build all
./l2 doctor

Before you build.

Target architecturex86_64 for the kernel and rcl2.
Build hostLinux with the project’s compiler, kernel and ISO dependencies.
Build storageREADME guidance: approximately 2 GiB for the core source/build trees. Allow more for optional components.
Boot firmwareBIOS or UEFI; unsigned Limine requires Secure Boot off.
Runtime memoryNo universal tested minimum published here. Test your build in a VM and on the target hardware.
Optional desktopSeparate image and size budget. README recommends at least 256 MiB RAM.

Check your artifacts.

Record hashes of your local outputs. These are local checksums, not publisher signatures. Repeat the build with the same lockfile and toolchain to compare results.

Boot and installation notes →
sha256sum build/out/vmlinuz-l2 \
  build/out/initramfs-l2 \
  build/out/l2.iso
